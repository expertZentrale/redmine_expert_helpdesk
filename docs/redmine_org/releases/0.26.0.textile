h3. Added

* *Look mails up by Message-ID through the REST API.* @GET /helpdesk/messages.json?message_id=…@ takes up to 50 Message-IDs, with or without angle brackets, and returns the matching mail log entries with their ticket and project, across every project the caller can see (@project_id@ narrows it). An ID that is not listed never reached a ticket, which is what you need to match a mail server's message trace against Redmine. The mail log of a ticket (@include=messages@) now carries each mail's @message_id@ as well.

h3. Upgrade notes

No new migrations, no new settings, no new permissions: the lookup follows the ticket API (@view_issues@ plus the Helpdesk module). Replace the plugin directory and restart Redmine. If the plugin is copied into a Docker image, rebuild the image before restarting the container; a restart alone keeps running the old code.
